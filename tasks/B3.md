# B3 — Global quick-search (Cmd-K)

## Task (delivered verbatim, identical to every framework arm)

> Add a global quick-search to the dashboard.
>
> - Pressing Cmd-K (Mac) or Ctrl-K opens a search overlay from any
>   page of the signed-in app; a visible search affordance in the
>   sidebar opens it too. Escape closes it.
> - Typing searches invoices AND customers as the user types, and the
>   result list updates with every keystroke.
> - Matches can number in the dozens and the list shows them all in a
>   scrollable panel — grouped by kind (customers, invoices) — not
>   capped to a handful.
> - Every result row is interactive: an invoice row links to that
>   invoice's edit page AND carries the existing inline status toggle,
>   working right from the overlay; a customer row navigates to the
>   invoices page filtered to that customer.
> - The list is keyboard-navigable: arrow keys move the highlight,
>   Enter activates the highlighted row, and the highlight is visible.
> - Navigating from a result closes the overlay and lands on a fully
>   functional page; every existing behavior (search, sorting,
>   pagination, freshness after mutations) is unchanged.

## Acceptance (verified by the harness, not the building agent)

1. Cmd/Ctrl-K opens from dashboard, invoices, and customers pages;
   Esc closes; sidebar affordance opens it.
2. A broad query (e.g. a common surname) renders DOZENS of live rows
   in one scrollable panel, updating per keystroke; both kinds appear,
   grouped.
3. Invoice row: edit link works; status toggle flips from the overlay
   and the B2 freshness guarantee holds afterwards (dashboard cards
   current).
4. Customer row: lands on /dashboard/invoices filtered to that
   customer.
5. Arrow keys + Enter operate the highlight; Esc restores the page.
6. B1/B2 spot-checks pass; production build passes.
